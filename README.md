# AI Resistor Scanner

## Overview

AI Resistor Scanner is a web-based application that uses Deep Learning and Computer Vision to automatically identify resistor colour bands from uploaded images and predict the corresponding resistance value. The application integrates a React frontend, Node.js backend, and a TensorFlow Lite model to provide accurate and efficient resistor value prediction.

---

## Features

- Upload resistor images for analysis
- Automatic resistor colour band detection
- AI-based resistance value prediction
- User-friendly and responsive web interface
- Deep learning-powered image classification
- Fast and accurate prediction results

## How to Run

### Clone the Repository

```bash
git clone https://github.com/bhagyashreepatil04/resistor-scanner.git
cd resistor-scanner
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```
